# Single-pass competitor research overstates rivals — make a second agent try to refute it

**Problem** — A competitive review needed feature-by-feature claims about 21 products. First-pass research read each vendor's own site and produced confident, well-cited profiles. Spot-checking one claim against a second source showed it was wrong, which put every other claim in doubt.

**Approach** — Rather than re-research, a second agent per product was given the first agent's report and told to *refute* it: demand a feature page, help article or store listing for each claim, and mark anything supported only by marketing copy as unverifiable rather than true. The refutation framing is what did the work — the same sources, read with the opposite goal, produced different answers. Definitions were pinned in the prompt so "proactive" could not be granted to a tagline: reactive = acts only when addressed, proactive = works unprompted on connected data, agentic = takes outward actions.

**Solution** — Corrections landed in `docs/competitive-review.md`. Four products moved *down* from proactive to reactive once a feature page was demanded (one vendor's help centre returned zero articles for "proactive"; another's blog had a section headed "Proactive" describing nudges absent from the product). Several gained features the first pass missed. One vendor's comparison claim about a competitor was simply false. The finished matrix uses the corrected values and the method appendix lists what changed.

**Rule** — For any competitive or market claim that will drive a decision, run a second agent whose instruction is to refute the first, not to confirm it, and require a primary artifact (feature page, help article, store listing) per claim. Pin the classification definitions in the prompt, or the model adopts the vendor's vocabulary. Treat a vendor's own "best X of YEAR" roundup as a source of feature facts only, never rankings or claims about rivals — those are marketing, and at least one will be false. Expect the correction to run in both directions: the second pass adds features as often as it removes them.

**Dead ends** — Trusting confident citations: the first pass cited real URLs and still got the claims wrong, because it read the marketing page rather than the help centre. Re-reading the same page the first agent cited and agreeing — the prompt has to demand a *second, independent* source or a page that would contradict the claim.
