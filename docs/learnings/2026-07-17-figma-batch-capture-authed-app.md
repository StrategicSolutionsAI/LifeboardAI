# Batch-capturing an entire authed Next.js app into Figma (B&W wireframes)

**Problem** — "Create a Figma file and wireframe every page of this app, accurately" — 29 routes, most behind Supabase auth, all served under a nonce CSP that blocks any injected external script.

**Approach** — (1) Don't hand-build 29 screens in Figma; drive the Figma MCP `generate_figma_design` capture pipeline against the running dev server so accuracy is free. (2) The tool's "local = script-tag, external = Playwright" rule breaks here: the nonce CSP blocks the capture script and the auth wall blocks anonymous visits. Use the *external* recipe on localhost: Playwright with a `page.route` interceptor that strips `content-security-policy` headers, inject `capture.js` source via `page.evaluate`, then call `window.figma.captureForDesign({captureId, endpoint})`. (3) Authenticate the browser with the existing magic-link cookie-mint pattern (docs/learnings/2026-07-16-authed-playwright-supabase-session.md) — public auth pages (/login, /signup) must be captured WITHOUT cookies or middleware redirects them to /dashboard. (4) Batch: request 5–7 single-use capture IDs per round (parallel MCP calls), run 5–7 Playwright captures concurrently (`&` + `wait`), then poll each ID once — the poll, not the script, is the source of truth, because `captureForDesign`'s promise never resolves even on success; race it against a 90s timeout and close. (5) Captures land as top-level frames on one Figma page → rename to routes, grid into rows via one `use_figma` call. (6) B&W pass: one parallel `use_figma` call per frame walking `findAll` — SOLID fills/strokes/effect colors → luminance gray, IMAGE fills → flat gray, gradient stops → gray; load every font from `getStyledTextSegments(['fontName'])` first or text mutations throw.

**Solution** — Scratchpad scripts `auth-cookies.js` + `capture-page.js` (session scratchpad, pattern in this note); Figma file `LifeboardAI Wireframes`, 29 frames, 6,050 nodes converted, zero errors.

**Rule** — To capture localhost pages into Figma when the app has a strict CSP or an auth wall, ignore the "local = script-tag" instruction: use Playwright with CSP-header stripping + script injection (the documented external-site recipe works on localhost), mint session cookies via the Supabase magic-link pattern, capture public auth pages cookie-less, and always confirm success by polling the capture ID — never by waiting for `captureForDesign` to resolve.

**Dead ends** — Waiting for `captureForDesign`'s promise (hangs forever; the first capture burned a 240s timeout while having already succeeded server-side). Adding the capture `<script src>` to the layout (nonce CSP blocks it, and `connect-src` would also block the submit). Emoji glyphs can't be made grayscale via fills — their color is baked into the font; accept or strip the characters.
